# 01_cover

各位来宾、各位工艺和现场工程师大家好。今天我们通过这十页资料，系统介绍基于 SINUMERIK 平台的 TEST 数控内螺纹磨床 HMI 3.29.0 操作软件。右侧大家看到的就是系统的欢迎页实机界面，操作面板按 CUSTOM 键即可直达。整个 HMI 将砂轮修整、自动与手动对刀、四级工艺磨削、八项专机扩展功能以及统计备份运维整合为一体，接下来我们按实际加工与管理顺序逐一展开。

---

# 02_hmi_navigation

在界面架构上，系统采用清晰的双层菜单设计。第一层欢迎页集中了出厂信息、参数备份恢复、配件寿命、加工统计以及右下角扩展进入的机床配置等运维管理入口；点击底部「用户界面」软键，即可进入第二层加工主区，底部五个水平软键在磨削参数、工艺参数、修整参数、自动对刀和返回欢迎页之间一键切换。需要特别留意操作面板在按下「循环启动」后的优先级规则：只要打开了空运行使能就会优先空载热机，其次是自磨夹具，再依次是修整、自动对刀、手动对刀、C 轴旋转，只有功能键全部熄灭时才执行正常磨削，过程中随时可以按退刀键安全中止并退出工件。另外，在任意页面选中参数后按 HELP 键，下半屏就会直接弹出该参数的说明与修改权限，大大降低了新操作员的上手门槛。

---

# 03_wheel_dressing

磨削精度首先取决于砂轮修整。系统内置了四种修整触发机制：更换新砂轮后执行的新砂轮修整，内螺纹模式下程序会按新砂轮直径减去最大磨削直径再除以二自动计算粗修与精修次数；日常恢复齿形的旧砂轮修整；磨削过程中按工艺表间隔自动执行的磨削中精修；以及按加工件数触发的周期精修。根据机床硬件配置，系统支持使用碟形轮两轴联动的 X-W 插补修整，以及使用成型滚压轮直线复制齿形的成型 X 修整。标定时需准确输入修整中心距和修整中心，两个关键参数旁默认闭合了锁定开关防止误改；每次修整结束后，系统都会自动更新砂轮直径并同步补偿磨削位置，无需重新对刀，当砂轮小于最小磨削直径时还会自动报警保护。

---

# 04_profiles_rollers

在齿型与修整轮适配方面，系统覆盖了多种复杂内螺纹与滚珠丝杠需求。三角与梯形齿型除了常规单斜面外，均可开启扩展上下两段不同角度斜面的模式，梯形齿型还提供按中径宽度与高度定义的戴帽模式及平顶、锥顶选项。针对滚珠丝杠和螺母的哥特式双圆弧滚道，界面右侧这张双圆弧页面采用「初始、调整、当前」三列闭环修正，打开自动计算后即可依据标准切换系数（常用一点一一）和钢球直径、接触角（常用四十五度）自动生成圆弧半径与水平偏心，并支持小角度整齿旋转与右侧高低微调。配合单滚轮、方滚轮、双滚轮和滚压轮的参数标定（通过核对初始接触 X 是否等于实测接触坐标即可验证中心距准确），以及选配的多线多牙修整与齿高补偿功能，可以兼顾复杂齿型精度与修整效率。

---

# 05_alignment

完成修整后进入对刀环节，核心目标是准确测出加工起始角 C 与初始接触 X。系统提供手动与自动两条路径：手动对刀支持插补对刀和静止对刀，操作员通过 DRF 手轮微调砂轮落入螺纹槽后按退刀键即可记录坐标并安全退出，在批量生产时设为「不是首件」还能锁定初始接触 X 不变，确保整批工件尺寸一致。对于配备了测量机构的机床，自动对刀涵盖内滚道接近开关与反向孔测头两大体系，内滚道模式可自动探找槽两侧牙侧取中点，碰牙顶时还能自动平移重试最多五次；反向孔测头模式则覆盖圆形和腰形反向孔（支持常规与只测 C）、右端台阶、右端定位孔以及外圆面右端反，并具备先快后慢复测和右端超阈值（默认零点零五毫米）防撞报警。标定好测量水平距 Z 后，后续若有微弱偏刀只需在「对刀结果调整」中直接叠加修正，无需重新标定测量机构。

---

# 06_process_grinding

对刀就绪后，我们来看核心的多级工艺磨削与测后闭环补偿。系统将单件调整试磨与批量生产分别保存在两套独立的工艺参数表中，每张表按粗磨、半精磨、精磨、终磨四道工序顺序执行。从左侧参考参数表可以看到，随着工序推进，进给深度从粗磨的零点零四毫米逐步收细到终磨的零点零零五毫米，头架转速也由每分钟五十转降至三十转，内螺纹砂轮线速度参考每秒二十米，并在粗磨与半精磨阶段按设定次数自动插入精修。批量模式下如果加工中断，还可以指定从某道工序的某次循环继续加工。加工完测量工件后，任何常见误差都有一一对应的调整入口：中径偏差改中径补偿，两侧不均改偏刀补偿，螺距累积误差用全长导程补偿，两端中径不一致用全长锥度补偿，局部段差用分段补偿，批量修整漂移则通过磨削中补偿解决。

---

# 07_extensions_machining

面对各类非标或异形内螺纹工件，系统在机床配置开启后会在磨削界面右侧提供专项扩展功能。第一项环形槽磨削支持最多四组槽的槽数、槽距、槽升量和组间偏移设置，并在左侧实时显示已加工槽数。第二项螺距变换提供单段给定角度或终点变换，以及多段变螺距分段填写模式，配合平滑轨迹切换避免拐点冲击。第三项反向孔倒角可设定过渡角、倒角深度、平移角和两端预倒角，既支持手动输入各倒角 Z 坐标，也能在输入首孔位置后自动推算并支持位置与终点补偿。第四项变径磨削则可灵活设定两端无效牙角度、变径量与过渡角度，并选择每刀同步变径或在螺纹磨完后单独磨削变径段。

---

# 08_extensions_precision

除了异形结构加工，系统还针对长螺纹精度稳定与设备自维护提供了另外四项扩展能力。第五项分段补偿允许按检测报告从右端起设置分段数，逐段录入终点 Z 坐标、中径和导程补偿量，在自动磨削中生效；需要注意的是，同时开启反向孔倒角、变径磨削或变螺距时不会执行分段补偿。第六项空运行热机在设定安全的 Z 轴和 X 轴往复范围后，开启使能即可优先空载往复热机消除冷机温漂，热机完成后务必关闭使能。第七项自磨夹具支持在线修整和磨削夹具基准，保证装夹同心度，同样在完成后需要关闭开关。第八项 DIY 工艺模式则开放用户自定义子程序执行特种工序，启用期间标准工艺表会自动转为只读保护。

---

# 09_stats_life_backup

在车间连续批量生产与数据运维层面，系统提供了完善的追溯与防呆工具。通过欢迎页进入加工统计界面，表格会按砂轮序号自动记录每片砂轮完成的批量生产工件数和更换日期，更换新砂轮并启动新砂轮修整后即自动开启下一片记录；下方的修整轮生命周期区同时记录已修整次数与累计修整量，并在到达极限时提醒更换。配件寿命界面允许为每种关键配件设定寿命上限和报警阈值，超限后启动程序即暂停提示，更换后点击右侧重置图标即可清零并记录在滚轮更换历史中。参数备份恢复功能则支持全部参数或最多七百九十个自定义变量清单的备份，也支持从后部 USB 逻辑驱动器恢复；使用时需要注意，自定义列表文件需填写包含注释和空行在内的总行数，且备份或恢复完成后务必将模式选择改回「加工」，否则机床不会执行正常磨削。

---

# 10_security_summary

最后我们看整个系统的安全防护机制与全周期闭环价值。为了兼顾现场微调的便利性与核心参数的安全性，HMI 实施了严格的四级权限隔离：钥匙开关零档开放中径、偏刀等日常补偿微调；钥匙开关三档开放工件、工艺、修整、对刀和加工统计；用户口令控制参数备份恢复与配置入口；而涉及选配功能显隐、机床数据重置以及工艺参数极限范围的机床配置界面，则必须由屏幕生成挑战码并联系制造商获取解锁口令方可修改，严禁自行篡改。总体而言，TEST 数控内螺纹磨床 HMI 3.29.0 将修整、对刀、四级磨削、专机扩展、寿命备份与权限安全串联成一个完整闭环，建议设备现场投入使用时按「核对出厂选配配置、完成新轮标定与首件试磨、开启统计预警与定期参数备份」三步落地。谢谢大家。
